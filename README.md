# cartao_federacao_espacial
# 🚀 Federação Espacial — ID de Cadete

Projeto web para criar cartões de identificação personalizados para cadetes da Federação Espacial.

O usuário preenche os dados, seleciona uma foto, visualiza o cartão e pode imprimir ou salvar o resultado em PDF.

## ✨ Funcionalidades

* Preenchimento do nome do cadete.
* Preenchimento da idade.
* Registro do jogo favorito.
* Seleção de uma foto do computador.
* Pré-visualização do cartão em tempo real.
* Impressão do cartão pelo navegador.
* Opção de salvar o cartão em PDF.
* Botão para limpar os dados e criar outro cartão.
* Interface adaptável a diferentes tamanhos de tela.
* Suporte à instalação como aplicativo em navegadores compatíveis.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* GitHub Pages

O projeto não utiliza frameworks, banco de dados ou serviços externos.

## 💻 Como executar o projeto

1. Baixe o projeto e extraia os arquivos.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Preencha o nome, a idade e o jogo favorito.
5. Selecione uma foto do computador.
6. Clique em **Atualizar cartão**.
7. Clique em **Imprimir / Salvar em PDF**.
8. Escolha uma impressora ou a opção **Salvar como PDF**.

Não é necessário instalar dependências para utilizar as funções básicas.

## 🖨️ Como imprimir o cartão

Para obter melhores resultados:

1. Abra a opção de impressão.
2. Selecione o formato A4 e a orientação paisagem.
3. Ative a impressão de gráficos de fundo, se disponível.
4. Confira a pré-visualização.
5. Imprima ou salve o arquivo em PDF.

O resultado pode variar conforme as configurações do navegador e da impressora.

## 🌐 Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos do projeto para o repositório.
3. Mantenha a pasta `assets` e a imagem `modelo-cartao.jpg`.
4. Acesse **Settings → Pages**.
5. Em *Build and deployment*, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`.
7. Salve as configurações.
8. Aguarde a publicação e acesse o endereço fornecido pelo GitHub.

## 🪟 Como utilizar no Windows

Depois de publicar o projeto:

1. Abra o endereço do site no Microsoft Edge ou Google Chrome.
2. Procure a opção de instalar o site como aplicativo no menu do navegador.
3. Instale o aplicativo, caso a opção esteja disponível.
4. Procure-o no menu Iniciar do Windows.

A disponibilidade da instalação depende do navegador e das configurações do site.

## 🔒 Privacidade

* Os dados são processados localmente no navegador.
* A foto selecionada não é enviada automaticamente para um servidor.
* O projeto não possui banco de dados.
* Os dados preenchidos não são armazenados automaticamente para visitas futuras.
* O PDF é gerado pela função de impressão do navegador.

**Importante:** antes de utilizar ou compartilhar fotografias, verifique se existe autorização para o uso da imagem, especialmente quando envolver crianças e adolescentes.

## 🎨 Personalização

* `index.html`: estrutura e campos do formulário.
* `style.css`: cores, aparência, posicionamento e impressão.
* `script.js`: atualização do cartão, seleção da foto e impressão.
* `manifest.json`: configurações de instalação do aplicativo.
* `service-worker.js`: recursos de funcionamento em cache.
* `assets/modelo-cartao.jpg`: imagem utilizada como modelo do cartão.
