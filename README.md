# Cartão de Identificação — Federação Espacial / ID de Cadete

Projeto simples feito com HTML, CSS e JavaScript. Não precisa de banco de dados nem envia dados para um servidor.

## Como usar
1. Extraia todos os arquivos mantendo a pasta `assets`.
2. Abra `index.html` no navegador para testar.
3. Preencha nome, idade e jogo favorito; selecione uma foto.
4. Clique em **Imprimir / Salvar em PDF**.
5. Na janela de impressão, selecione **Salvar como PDF** ou uma impressora. Para melhores resultados, mantenha a impressão em **A4 paisagem**, escala padrão e gráficos de fundo ativados.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os arquivos e pastas deste projeto para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em *Build and deployment*, escolha **Deploy from a branch**, selecione `main` e `/ (root)` e salve.
5. Aguarde a publicação e abra o endereço do GitHub Pages.

O botão de instalação pode aparecer quando o site é aberto por HTTPS no GitHub Pages, em um navegador compatível.

## Atalho no Windows
Depois de publicar e abrir o site no Microsoft Edge ou Google Chrome:
- **Edge:** menu `...` → **Aplicativos** → **Instalar este site como um aplicativo** (se disponível).
- **Chrome:** menu `⋮` → opção de instalar/salvar o site como aplicativo (o nome pode variar).
- Depois de instalado, procure o aplicativo no menu Iniciar. Também é possível clicar com o botão direito e fixá-lo, conforme as opções do Windows.

## Observações
- Os dados digitados e a foto ficam apenas na página aberta; não são guardados automaticamente nem enviados para um servidor.
- O PDF é criado pela função de impressão do próprio navegador, sem biblioteca externa.
- Se quiser guardar o cartão, escolha **Salvar como PDF** na janela de impressão.
